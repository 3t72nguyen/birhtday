# Birthday Cake 37

Animated birthday cake: 37 candles, Happy Birthday song, blow-out, 37 balloons, confetti and a "Happy 37th Birthday" banner.

## Host on GitHub Pages
1. Create a new repository and upload all files from this folder to its root.
2. Settings > Pages > Deploy from a branch > main / (root) > Save.
3. After a minute the site is at https://YOUR-NAME.github.io/REPO-NAME/ . Send that link on Viber.

## Install on iPhone
Open the link in Safari > Share > Add to Home Screen.

Needs internet the first time (Google Fonts). Turn sound on.
